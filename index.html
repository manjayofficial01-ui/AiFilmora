AiFilmora 2.2.2 — 15 Filmora shader transitions · Toolbar order · ruler-drag zoom · drag auto-scroll

Filmora-style library shell around the real Filmora 14 assets in assets/.

  • 15 Filmora shader transitions — canvas ports of the real GPU shaders in assets/resources/wfx_effect/Transition/*.frag: Cross Zoom, Push, Drop Bands, Erase Wipe, Linear Wipe, Pinwheel, Pixelate, Roll Clockwise, Round Zoom Out, Skew Split, Doorway, Whirl, Evaporate (real mask PNG), Fade Black/White with the sine curve from the .frag source. Grouped under a "Shader" rail filter in Transitions, with live preview + apply + undo.
  • Timeline toolbar order — Undo, Redo, Mute Clip, Trim Start, Trim End, Split, Detach Audio, Beat Sync, Beat Options, Clear Beats, Delete.
  • Ruler-drag zoom that works — drag the timeline ruler in any direction to zoom (right/up = in, left/down = out); click still seeks. Zoom stays view-only and never changes clip lengths.
  • Drag auto-scroll — holding a clip near the panel edges keeps scrolling the timeline (up/down + left/right) with the track labels in sync, so clips reach off-screen tracks.
  • Wrapping inspector tabs — the right-panel tabs arrange downward into extra rows when the panel shrinks instead of hiding.
  • Real Save for project + video — Save / Save as writes a .aifimora.json file and Export writes a real captured video file. Both ask for folder + file name, with Use as default save location and Ask every time checkboxes remembered in Preferences → Folders.
  • Full-height right inspector — the right panel is now one single column top-to-bottom; the timeline spans only the left area.
  • Ruler-drag zoom — drag the timeline ruler up/down (or Alt+drag) to zoom in/out; drag left/right to scrub. Zoom is view-only and never extends video, audio, or file lengths.
  • Custom AI providers + models — add any OpenAI-compatible endpoint (name + Base URL + models) and add custom model ids to any provider in the AI panel.
  • Collapsible Project Info card — the inspector's Project header now has a Hide / Show toggle (keyboard accessible) so the metadata card can collapse fully; your choice is remembered and can also be changed in Preferences → General.

All new content is read from the local Filmora 14 install (dev use). Preset bodies are still re-implemented in the browser — no native shaders or DLLs are loaded.

Filmora's preset bodies ship as GPU shaders and native DLLs, which a browser cannot load. What we use is the published metadata — names, categories, parameter ranges and real thumbnails — and we say so in each panel.

  • Ctrl+Z Undo · Ctrl+Y / Shift+Z Redo
  • S Split at playhead · Ctrl+S Save

  • J / L −2s / +2s · K Pause
  • ← → Frame step · Shift 1s
  • Alt+↑/↓ Move clip to another track
  • ↑/↓ Nudge clip start time
  • Drag clips vertically between compatible lanes
  • + / − Timeline zoom
  • M Focus AI Mate · T Text-based edit
  • P Pen Tool · N Add chapter · Ctrl+Shift+N Export chapters
