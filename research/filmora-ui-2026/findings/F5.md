# F5: Filmora export, save properties, preferences

## Findings

### [1] Filmora project files use the proprietary `.wfp` extension and store only media references (filenames/paths), not the source media itself; an optional archive mode can bundle sources with the project.
- quote: "The project (. wfp format) you create in Filmora contains the settings you select for each sequence in the timeline, as well as editing decisions, effects, and music used in the project. Filmora project files don't store the source videos, audio, or images. They only save a reference to these types of media files based on the file names and locations."
- url: https://filmora.wondershare.com/guide/create-a-project.html
- source_type: primary
- published: unknown
- confidence: high

### [2] Save Project / Save Project As is under File (hotkey Ctrl+S) and writes a `.wfp` that only Filmora can open.
- quote: "you can click File > Save Project or Save Project As, or use the hotkey Ctrl+S to save the edited project to your computer... The project will be saved as a file with the extension. wfp. And it can only be recognized and opened by Filmora."
- url: https://filmora.wondershare.com/guide/create-a-project.html
- source_type: primary
- published: unknown
- confidence: high

### [3] Project Settings (File > Project Settings) expose aspect ratio, resolution, and frame rate; default aspect ratio is 16:9 with 1:1, 9:16, and Custom options; project audio sample rate can be set to 44.1kHz or 48kHz.
- quote: "You can also set the resolution, aspect ratio, and frame rate for the project as you like under File > Project Settings. ... The default aspect ratio is 16:9, but you can change it to 1:1 or 9:16 if you want to make videos for Instagram or other social media, or you can select Custom to customize your aspect ratio."
- url: https://filmora.wondershare.com/guide/create-a-project.html
- source_type: primary
- published: unknown
- confidence: high

### [4] Project Settings audio sample rate configuration (44.1kHz or 48kHz) is documented as a high-precision export feature applied at project level.
- quote: "You can now set the audio sample rate to 44.1kHz or 48kHz in the project settings, ensuring better audio fidelity during export."
- url: https://filmora.wondershare.com/guide/export-to-local.html
- source_type: primary
- published: unknown
- confidence: high

### [5] Export dialog offers six destinations: Export to Local, Export to Device, Export to YouTube, Export to TikTok, Export to Vimeo, and Burn a DVD; export settings can be customized and saved to reuse.
- quote: "Filmora provides six ways to export your videos. Here is the introduction to the six ways. You can customize the export settings and save them to apply the same settings next time."
- url: https://filmora.wondershare.com/guide/export-to-local.html
- source_type: primary
- published: unknown
- confidence: high

### [6] Export to Local format list is MP4, AVI, WMV, AV1, MOV, GoPro CineForm, F4V, MKV, TS, 3GP, MPEG-2, WEBM, GIF, MP3; the support FAQ lists the same video set plus HEVC (H.265) and AV1 MP4 as distinct video formats.
- quote: "It supports to export as MP4, AVI, WMV, AV1, MOV, GoPro Cineform, F4V, MKV, TS, 3GP, MPEG-2, WEBM, GIF, MP3."
- url: https://filmora.wondershare.com/guide/export-to-local.html
- source_type: primary
- published: unknown
- confidence: high

- quote: "Filmora supports exporting in the following common video formats: .mp4, .wmv, .av1 mp4, .hevc (H.265), .avi, .mov, .gopro cineform, .f4v, .mkv, .ts, .3gp, .mpeg‑2, .webm, .gif"

### [12] Advanced export supports PCM audio encoding with selectable bit depth; pure-audio WAV export allows 44.1kHz or 48kHz sample rate and bit depth up to 32-bit.
- quote: "In the Advanced interface, you can select PCM encoding for audio format and set the bit depth, allowing for more precise audio quality control. ... When exporting pure audio in WAV format, users can choose the sample rate (44.1kHz or 48kHz) and adjust the bit depth up to 32-bit for maximum audio quality."
- url: https://filmora.wondershare.com/guide/export-to-local.html

### [14] Preferences tabs documented as General, Folders, Editing, Save, and Performance; most prefs persist until changed, while scratch-disk prefs are saved with each project and restored when that project is opened.
- quote: "You can set up General, Folders, Editing, Save, and Performance as you want. When you finish setting, click ok to apply. ... Most of these preferences remain in effect until you change them. The preferences you set for scratch disks, however, are saved with your projects. Whenever you open a project, it automatically defaults to the scratch disks you selected for it when you set up that project."
- url: https://filmora.wondershare.com/guide/panel-layout.html
- source_type: primary
- published: unknown
- confidence: high

### [15] Appearance (Light Mode / Dark Mode / System Default) is under File > Preferences > General; default UI skin follows the OS when System Default is chosen at setup.
- quote: "To toggle between Light and Dark modes, go to File > Preferences > General and choose Light Mode or Dark Mode under Appearance. Click Ok to save the change. ... The skin color of the program will be consistent with your operating system if you choose System Default during setup."
- url: https://filmora.wondershare.com/guide/panel-layout.html
- source_type: primary
- published: unknown
- confidence: high

### [16] Automatic project backup is configured under Preferences > Folders > Backup Settings: enable automatic backup and set the backup interval time (this is the autosave/backup UI).
- quote: "Open Filmora, click Preferences, then Folders. Under Backup Settings, you can enable automatic backup and set the backup interval time."
- url: https://support.wondershare.com/how-tos/filmora/how-do-i-set-up-automatic-project-backup.html
- source_type: primary
- published: unknown
- confidence: high

### [17] Resource/download storage path is Preferences > Folders > Default Storage Location; Wondershare warns against pointing it at external or cloud drives to avoid read issues.
- quote: "To change the storage directory for resources downloaded within Filmora, you need to directly modify the Default Storage Location under File - Preferences - Folders. Note: Please avoid changing the storage directory to an external hard drive or cloud drive to prevent potential read issues."
- url: https://support.wondershare.com/how-tos/filmora/where-do-i-change-the-resource-storage-directory.html
- source_type: primary
- published: unknown
- confidence: high

### [18] Export can target one or more selected timeline clips via right-click (not only whole-project export); that dialog offers video format, quality level, and save path (local folder or devices).
- quote: "Select one or more video clips on the timeline and right-click to export the clip(s) easily and fast instead of having to export the whole project. ... you can now select the video format, quality level, the save path (local folder or devices) and other settings."
- url: https://filmora.wondershare.com/guide/export-share-video.html
- source_type: primary
- published: unknown
- confidence: high
