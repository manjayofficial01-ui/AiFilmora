# F3: Filmora properties/inspector content-aware panels

## Findings

### [1] Filmora's right-side Property Panel is content-aware and shows video, audio, color, and speed properties for whatever is selected in the Timeline Panel or Preview Window.
- quote: "The Property Panel shows you all relevant information on your project to display your clip's video, audio, color, and speed properties in the Timeline Panel or Preview Window."
- url: https://filmora.wondershare.com/guide/panel-layout.html
- source_type: primary
- published: unknown (live guide; covers Filmora 12/13/14+ layout)
- confidence: high

### [2] Windows workspace has four core panels (Property, Player/Preview, Media, Timeline) and six layout modes: Default, Organize, Edit (property panel extended to bottom), Short Video, Classic, and Dual (multi-monitor).
- quote: "There are six layout models to choose from when editing your projects. You can choose between: Default… Organize… Edit: The property panel will be extended to the bottom line in this mode… Short Video… Classic… Dual."
- url: https://filmora.wondershare.com/guide/panel-layout.html
- source_type: primary
- published: unknown
- confidence: high

### [3] Panels resize by dragging border handles (horizontal left/right arrows, vertical up/down arrows); the Player Panel can float as an independent panel or be docked back by dragging.
- quote: "If you want to resize any of the panels, drag the resizing icon at the borders between each panel… The Player Panel can also be used as an independent panel or replaced with the default position by simply dragging the panel."
- url: https://filmora.wondershare.com/guide/panel-layout.html
- source_type: primary
- published: unknown
- confidence: high

### [4] Project-level settings are edited via File > Project Settings and include aspect ratio, resolution, and frame rate; projects save as .wfp and reference (not embed) source media.
- quote: "Project settings include aspect ratio, resolution, and frame rate. You can adjust the parameters you want." / "The project will be saved as a file with the extension .wfp."
- url: https://filmora.wondershare.com/guide/panel-layout.html
- source_type: primary
- published: unknown
- confidence: high

### [5] When a text/title clip is selected, the properties panel exposes a Text section with Basic and Bubble subsections: text box, font, text color, alignment, letter case, bold/italic/underline; Shadow (Opacity, Blur, Distance, Apply to All); Shape (strength, duration, loop); Glow (type, color, intensity); and a Save preset control at top-right.
- quote: "enable the Text section from the properties panel and input the desired text… You can change the font, text color, alignment, and letter case… Under the Basic section, locate the Shadow option and turn its toggle on. Now adjust the Opacity, Blur and Distance… Click on the Apply to All button… turn the toggle on for Shape… Adjust the strength, duration, and loop… Turn the toggle on for the Glow option."
- url: https://filmora.wondershare.com/guide/edit-and-customize-texts.html
- source_type: primary
- published: unknown
- confidence: high

### [6] Selecting/double-clicking an audio clip opens the right-side editing panel with volume, pitch, balance, fade-in/fade-out, and Equalizer settings.
- quote: "Double-click the audio clip in the timeline to access the editing panel on the right, where you can modify sound properties. Adjust settings like volume, pitch, balance, and apply fade-in or fade-out effects… Equalizer settings."
- url: https://filmora.wondershare.com/guide/add-and-modify-audio.html
- source_type: primary
- published: unknown
- confidence: high

### [7] Video/clip Basic properties include Transform (toggle): Scale via Width and Height sliders, Position, Path Curve, Anchor Point, and Rotation; a per-parameter Keyframe icon marks animation start points.
- quote: "access the Basic section… locate the Transform option and turn its toggle on. Adjust the Scale by dragging the Width and Height sliders. You can also change the Position, Path Curve and Anchor Point… Click the Keyframe icon to mark the starting point for the transformation effect."
- url: https://filmora.wondershare.com/guide/transform.html
- source_type: primary
- published: unknown
- confidence: high

### [8] Color grading is entered from the right properties panel Color section, with subsections Basic (LUT, temperature, vibrance, etc.), HSL (per-color Hue/Saturation/Luminance sliders), Curves (Y/R/G/B plus Hue vs Sat, Hue vs Hue), Color Wheels (midtones/shadows/highlights), and HDR (Black, Dark, and other wheels).
- quote: "head to the properties panel on the right and enable the Color section. Opt for the Basic section… enable the LUT option… Access the HSL section… enable the Curves section… choose the required color from Y, R, G, or B… Hue vs Sat, Hue vs Hue… After acquiring the Color Wheels section… midtones, shadows, and highlight wheels… access the HDR option from the properties panel and adjust the Black, Dark, and other wheels."
- url: https://filmora.wondershare.com/guide/color-hsl.html
- source_type: primary
- published: unknown
- confidence: high

### [9] Keyframe UI: right-click a timeline clip → "Show Keyframe Animation" opens the Keyframe Graph Editor / Keyframe Panel at the timeline; it uses Bezier curves for animation easing.
- quote: "right click on this clip in the timeline. From there, click the \"Show Keyframe Animation\"… The keyframe graph will be shown at the timeline… it utilizes Bezier curves for enhancing the animations."
- url: https://filmora.wondershare.com/guide/keyframe-graph-editor.html
- source_type: primary
- published: unknown
- confidence: high

### [10] Selecting a transition and double-clicking opens the properties panel where duration and transition position can be adjusted; duration can also be trimmed by dragging the transition edges on the timeline.
- quote: "Once the transition is added to the timeline, double-click it to open the properties panel. From here, you can change the duration and adjust the transition position. Another way to adjust duration is by dragging the starting or ending edge of the transition directly inside the timeline."
- url: https://filmora.wondershare.com/guide/modify-transitions.html
- source_type: primary
- published: unknown
- confidence: high

### [11] Project creation accepts aspect ratio at the Startup Window (default 16:9, also 1:1, 9:16, Custom) and File > Project Settings can change resolution, aspect ratio, and frame rate after creation.
- quote: "Select the corresponding Aspect ratio at the top of the Startup Window… The default aspect ratio is 16:9, but you can change it to 1:1 or 9:16… or select Custom… You can also set the resolution, aspect ratio, and frame rate for the project as you like under File > Project Settings."
- url: https://filmora.wondershare.com/guide/create-a-project.html
- source_type: primary
- published: unknown
- confidence: high

### [12] Compositing provides an Opacity control to make an entire clip uniformly transparent or semi-transparent (video/image editing settings).
- quote: "To make an entire clip uniformly transparent or semi-transparent, use the Opacity effect in Compositing. You can set a selected clip's opacity in video or image editing settings."
- url: https://filmora.wondershare.com/guide/transform.html
- source_type: primary
- published: unknown (quoted from Recommended User Guide summary on transform page)
- confidence: medium
