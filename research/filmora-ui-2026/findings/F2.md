# F2: Filmora library panel taxonomy and media workflows

## Findings

### [1] Filmora Windows Media Panel (aka "Media Library") top-level tabs are Media, Stock Media, Audio, Titles, Transitions, Effects, Stickers, and Templates — Filters is documented as a separate top-level tab in its own guide page but is omitted from the panel-layout bullet list (likely 9 tabs total in 14/15 UI).
- quote: "Media: Where your media files are imported. • Stock Media: Choose royalty-free stock media from GIPHY/Pixabay/Unsplash. • Audio: Explore Filmora's audio files. • Titles: Choose between available preset titles to use on your video. • Transitions: Make your project eye-catching by using different Transitions. • Effects: Choose eye-popping effects for your video. • Stickers: Add elements to your projects like Stickers. • Templates: Allows you to split screen videos with preset Templates."
- url: https://filmora.wondershare.com/guide/panel-layout.html
- source_type: primary
- published: unknown (live as of 2026-09-22; page text cites Filmora 12/13/14)
- confidence: high

### [2] Filters is accessed via a top-level "Filters" tab with three apply methods: select-and-add, hover Plus icon, or drag-and-drop onto a timeline clip (drag applies the filter to the whole clip).
- quote: "Method 1: Open your project, go to the Filters tab… Method 2: Hover your mouse over the filter you want. When you see a Plus icon in the middle, click it… Method 3: Drag the filter and drop it directly onto the video clip in your timeline… Filters will be applied to the whole video clip this way."
- url: https://filmora.wondershare.com/guide/filters.html
- source_type: primary
- published: unknown
- confidence: high

### [3] Media tree under Media for use documents Project Media, Global Media, Cloud Media (My Cloud Media + Downloads), Stock Media (Mine → Favorites + Downloads, plus AI Image and Library), Influence Kit, Adjustment Layer (Preset/Custom), Compound clip, and Relink Media.
- quote: "Project media refers to the media files you used for your videos… Global Media: Import media here to use it in multiple projects… Cloud Media: … My Cloud Media: You can drop or upload your video clips, images, or audio here to save them to your Cloud for backup. • Downloads: The media downloaded from your Cloud will be displayed here."
- url: https://filmora.wondershare.com/guide/media-for-use.html
- source_type: primary
- published: unknown
- confidence: high

### [4] Project Media supports right-click "add a new folder"; Global Media folders can be renamed, deleted, and nested; Relink Media replaces an imported source only when the replacement has the same duration.
- quote: "Right-click on Project Media, you can add a new folder. ● Right-click on Folder; you can rename and add a new folder… Right-click on Global Media, you can add a new folder. ● Right-click on Folder; you can rename, delete and add a new folder… If the selected file and the clip you used in the project have different durations, they cannot be relinked."
- url: https://filmora.wondershare.com/guide/media-for-use.html
- source_type: primary
- published: unknown
- confidence: high

### [5] Project Media search/filter bar has four type filters (All, Video, Audio, Image); view is Large/Medium/Small Thumbnail; sort by Name, Duration, Type, Date Created (Asc/Desc); group by None, Type, Date Created, Camera Name, Duration (Asc/Desc).
- quote: "On the right side of the Search Media bar, there are four filters here: All, Video, Audio, and Image… You can view by: Large Thumbnail View, Medium Thumbnail View, Small Thumbnail View. Your media files can be sorted by: Name, Duration, Type, Date Created, Ascending, Descending. Your media files can be grouped by: None, Type, Date Created, Camera Name, Duration, Ascending, Descending"
- url: https://filmora.wondershare.com/guide/media-for-use.html
- source_type: primary
- published: unknown
- confidence: high

### [6] Import into Media Library has three paths: File > Import Media (Media Files, Media Folder, Camera or Phone, Import with Auto Beat Sync), the Import control next to Project Media / the Project Media import area, and drag-and-drop into the Media Library; optional proxy-file prompt on import.
- quote: "There are 3 ways to import media files into Filmora… Click File > Import Media. Choose Import Media Files, Import a Media Folder, Import from a Camera or a Phone, or Import with Auto Beat Sync… There is also a click entry for Import in the bar next to Project Media… Method 3: Drag and drop media files into the Media Library… Filmora may ask you to create a proxy file"
- url: https://filmora.wondershare.com/guide/importing-media.html
- source_type: primary
- published: unknown
- confidence: high

### [7] Favorites are starred assets; they live under Mine > Favorites and support user tags with built-ins "Recently Used" and "Commonly Used", plus New Tag and Manage Tag (rename/delete).
- quote: "mark your favorites by clicking the \"Star\" icon… navigate towards the \"Mine\" category… select \"Favorites\"… choose \"Add Tag\", and… categorize your favorite elements in two tags named \"Recently Used\" and \"Commonly Used\"… select \"New Tag\"… choose the \"Manage Tag\" option… rename or delete it"
- url: https://filmora.wondershare.com/guide/mark-favorite-elements.html
- source_type: primary
- published: unknown
- confidence: high

### [8] Filters default duration is 5 seconds (edge-drag to change), alpha opacity is 0–100, and a "Protect skin tones" toggle exists in the property panel; favoriting turns the star green and lands under Mine-Favorite.
- quote: "The default length is five seconds, but you can drag the edge of the effect in your timeline to change its duration… The alpha opacity (transparency) property can have a value of 0-100… Enable Protect skin tones… Click on the favorite filter and find the Star icon, click on it and turn the star to green. Then, go to the Mine-Favorite category"
- url: https://filmora.wondershare.com/guide/filters.html
- source_type: primary
- published: unknown
- confidence: high

### [9] Effects tab exposes Video Effects categories including Trending, Basic, Timer, and Face-Off, with a search box (e.g. type "Mosaic"); add via drag to a track above the video or hover Plus; overlay effects default 5s and opacity 0–100; favorite via right-click Add to Favorites or Star on the cover.
- quote: "Click the Effects tab at the top, find Video Effects, and click Trending… type \"Mosaic\" in the search box… Hover your mouse over the overlay effect you want. Click the plus icon… the default length is five seconds… opacity… 0-100… Right click on a overlay effect in the Effects menu and select Add to Favorites. Or you can click the Star icon on the Effect cover."
- url: https://filmora.wondershare.com/guide/types-of-effects.html
- source_type: primary
- published: unknown
- confidence: high

### [10] Stickers library has 1000+ built-in stickers with category browse/download; add via + icon or drag-and-drop to timeline; double-click opens the right-side properties panel; delete via Delete key or right-click Delete; favorite via right-click Add to Favorites or star on thumbnail.
- quote: "With over 1000+ built-in stickers… Go to the top menu bar and click on the Stickers tab to open the sticker library. Browse through different categories and download the stickers… click the + icon on any sticker… or drag and drop the sticker directly onto the timeline… double-click it on the timeline. The settings panel will open on the right side… right-click on a sticker in the library and select Add to Favorites. You can also click the star icon"
- url: https://filmora.wondershare.com/guide/add-and-customize-elements.html
- source_type: primary
- published: unknown
- confidence: high

### [11] Transitions tab is a download-then-use library: download icon saves an asset locally, then drag to timeline at clip start/end or between two clips; double-click opens properties (duration/position) or edge-drag duration; favorites via right-click Add to Favorites.
- quote: "select the Transitions tab to access the transition library. Browse the available transition collection and click the download icon on any transition to save it to your library. After downloading, drag the selected transition to the timeline. You can place it at the beginning or end of a clip or position it between two clips… double-click it to open the properties panel… right-click a transition in the library and choose Add to Favorites."
- url: https://filmora.wondershare.com/guide/modify-transitions.html
- source_type: primary
- published: unknown
- confidence: high

### [12] Templates tab: Mine → Templates lists preset templates; click one to preview it, drag to timeline; a replaceable-segments box (e.g. "8 items can be replaced") shows segments above the timeline for footage/text swap before export.
- quote: "Go to the Templates tab at the top and click the Templates menu under the Mine category on the left side. You can see there are dozens of templates, click one to preview it, and then drag the template to the timeline… there will be a box indicating how many segments of the template can be replaced with materials… if this template has 8 items that can be replaced"
- url: https://filmora.wondershare.com/guide/edit-with-preset-templates.html
- source_type: primary
- published: unknown
- confidence: high

### [13] Stock Media tab sources are GIPHY, Pixabay, and Unsplash; its Mine category has Favorites and Downloads; hover Favorite while hovering a resource; also AI Image and Library nodes.
- quote: "Stock Media: Choose royalty-free stock media from GIPHY/Pixabay/Unsplash… Find the Mine tab at the top, where there are two categories: Favorites, Downloads… Click Favorite while hovering over a resource to add an tem to this folder… AI Image… Library - You can editing background materials here."
- url: https://filmora.wondershare.com/guide/panel-layout.html and https://filmora.wondershare.com/guide/media-for-use.html
- source_type: primary
- published: unknown
- confidence: high

### [14] Workspace layout modes that change Media Panel footprint: Default, Organize (media panel extended to the bottom), Edit (property panel extended), Short Video, Classic, Dual (multi-monitor).
- quote: "There are six layout models… Default… Organize: The media panel will be extended to the bottom line… Edit: The property panel will be extended… Short Video… Classic… Dual: This mode works best for people who are accustomed to multiple monitors."
- url: https://filmora.wondershare.com/guide/panel-layout.html
- source_type: primary
- published: unknown
- confidence: high
